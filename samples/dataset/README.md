# 子课题 1 OCR 基准样本集

本目录用于“多类型图片采集与 OCR 识别流程设计”的初始验证。包含六类、每类五个独立内容；每个内容提供标准图和扰动图，共 **30 个独立案例、60 张图片**。

**这一版全部为合成数据。** 拍照文档的桌面背景、纸张阴影与旋转由程序模拟；扫描件由程序渲染为灰度图。它们不是手机实拍或真实扫描仪输出，不能据此声称完成真实图片采集或证明真实场景准确率。现有 `samples/` 根目录的四张演示图保留，未重复计入本数据集。

## 样本覆盖

| 类别 | 目录 | 独立内容 | 图片数 | 推荐模式 |
|---|---|---:|---:|---|
| 拍照文档 | `images/photo_document/` | 5 | 10 | 通用 |
| 表格截图 | `images/table_screenshot/` | 5 | 10 | 表格 |
| 票据单据 | `images/receipt/` | 5 | 10 | 表格 |
| 试卷图片 | `images/exam/` | 5 | 10 | 深度 |
| 宣传海报 | `images/poster/` | 5 | 10 | 通用 |
| 扫描件 | `images/scan/` | 5 | 10 | 通用 |

每类的第 1—5 个内容分别测试轻微旋转、低对比度、模糊、缩小、噪声与 JPEG 压缩。扰动图不裁去正文，因此与对应标准图使用同一份标准文本。所有图片为 PNG 或 JPEG，均在当前前端 6MB 上传限制内；本版没有覆盖 BMP、WebP、手写字、遮挡、强透视和多栏版面。

## 文件说明

- [CATALOG.md](CATALOG.md)：逐个案例浏览图片和标准文本。
- `images/`：可直接选择上传的图片；`standard` 为基准条件，`challenge` 为扰动条件。
- `ground_truth/`：30 份 UTF-8 标准文本，标准图与扰动图共用。
- `annotations/`：段落阅读顺序和表格单元格文本；不包含图片坐标标注。
- `manifest.json`：60 张图片的类别、来源、模式、划分、变换参数、文件大小、分辨率和 SHA-256。
- `cases.json`：合成内容原文。标准答案由渲染源文本生成，尚未独立人工转录；其中单据、单位与活动信息均为测试内容。
- [COLLECTION.md](COLLECTION.md)：下一轮真实采集计划，当前真实采集数量为零。

## 开发集与评测集

每类的 `01`—`04` 归入 `development`，`05` 归入 `test`，即 24 个开发案例与 6 个评测案例。原图及其扰动图始终属于同一划分，避免把同一内容的变体当成独立评测内容。这里的 `test` 是初始回归评测集，不是大型独立测试集；同类样本共享渲染模板，不能代表广泛的版式泛化能力。

## 在当前项目中使用

1. 在服务端配置有效百度密钥，显式设置 `BAIDU_MOCK=0`，重启服务。
2. 从 `CATALOG.md` 选一组图片，按推荐模式分别上传标准图与扰动图。
3. 保留初始识别文本和原始响应，再进行人工编辑。对照对应 `ground_truth/` 文本检查差异。
4. 记录样本 ID、模式、精度、成功状态、耗时、错误类型和人工复核结果。没有实际执行过的样本不得填写成功或准确率。

**本样本集没有新增百度响应 fixtures。** Mock 模式按文件名读固定响应，不读取图片内容；即使上传后能显示结果，也不能作为这张图片的识别结果。本次生成与校验不会调用百度 API。

标准文本按从上到下的阅读顺序记录，表格按逐行、逐列顺序转录，以制表符分隔单元格。后续计算文字错误率时应明确空白与标点的归一化规则；表格结构正确性应另外比较行列和单元格，不能只比较拼接文本。

## 重建与校验

应用本身无需新增 Node.js 依赖。重建或校验工具使用 Python 3.10+ 与 Pillow；字体由本机读取，不随样本集分发。当前生成环境为 Pillow 12.3.0，具体字体文件名与哈希记录在 manifest 中。

```bash
# 从项目根目录运行；已安装 Pillow 的环境可跳过第一步。
python3 -m pip install -r samples/dataset/requirements.txt
python3 samples/dataset/build.py
python3 samples/dataset/validate.py

# 其他操作系统可以显式指定可用的中文字体。
python3 samples/dataset/build.py \
  --font /path/to/CJK-Regular.ttc \
  --bold-font /path/to/CJK-Bold.ttc
```

生成器使用固定噪声种子，没有网络请求。相同字体和相同 Pillow/编码环境下可复现输出；更换字体或图像库可能改变像素、换行和文件哈希，应重新生成并复核。生成器只写本数据集目录，不读取运行数据库、密钥或用户上传目录。
