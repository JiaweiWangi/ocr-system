# 真实图片采集计划

当前 `manifest.json` 中的 60 张图片均为合成基准，真实采集尚未开始。下一轮先采集下表中的 30 个独立案例；同一内容的多次拍摄和增强版本计为同一案例，独立数量另行记录。

| 类别 | 独立案例目标 | 当前真实采集 | 建议覆盖条件 | 采集方式 |
|---|---:|---:|---|---|
| 拍照文档 | 5 | 0 | 正视、轻微倾斜、弱光、折痕、小字 | 手机拍摄自有或获准使用的打印文档 |
| 表格截图 | 5 | 0 | 简单表格、合并格、空白格、小字、不同列宽 | 截取实际电子表格或网页表格，保留原文件 |
| 票据单据 | 5 | 0 | 收据、采购单、送货单、结算单、热敏小票 | 拍摄或扫描可使用的票据，核查隐私信息 |
| 试卷图片 | 5 | 0 | 中文正文、英文、数学公式、表格、混排 | 拍摄或扫描自编试题，或记录明确的使用来源 |
| 宣传海报 | 5 | 0 | 大小字混合、彩色背景、长网址、图文混排、低对比 | 采集获准使用的电子海报或拍摄自有海报 |
| 扫描件 | 5 | 0 | 黑白、灰度、复印件、轻微污点、多段正文 | 使用扫描设备输出图像，记录设备和分辨率 |

这些数量与条件是本项目的初始采集建议，不是学校验收标准。真实图片不必全部是困难样本，应保留清晰基线，便于区分接口问题与输入质量问题。

## 每个案例的入库记录

- 样本 ID、类别、原始文件名、采集日期、采集人。
- 来源、使用许可或授权说明；含隐私内容时记录脱敏方式。
- 设备或截图工具、分辨率、文件大小、光照与角度；未知项填写未知。
- 原图及脱敏后的评测图路径、各自 SHA-256；有变体时记录父案例 ID 和变换过程。
- 推荐识别模式、标准文本、标注人、复核人、不可辨认区域说明。
- 开发或评测划分；同一文档的所有图片和变体必须放在同一划分。

标准文本应独立对照图片转录并复核，不能直接复制 OCR 输出作为答案。确实无法辨认的区域需单独记录，并明确是否从文字错误率计算中排除。

## 入库检查

1. 核实图片能打开、正文未被意外裁去，记录格式与尺寸。
2. 用文件哈希排除完全重复图片；相同内容的不同拍摄归入同一案例。
3. 核对来源、隐私处理和标准文本，完成复核后再用于正式评测。
4. 单独建立真实样本 manifest；报告分别列出真实样本和合成样本，不能合并声称真实采集数量。
